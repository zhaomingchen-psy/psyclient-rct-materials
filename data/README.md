# Data

`aggregate/` — group-level summaries from Study 2 (n = 20 per arm at baseline):

| File | Contents | Manuscript |
|---|---|---|
| `self_efficacy_by_group_wave.csv` | CASES item-mean self-efficacy (HS, SM, CC) by condition × wave (T1–T6): n, mean, SD, SE | Figure 4, Table 6 context |
| `mi_indicators_by_group.csv` | Reflection-to-question ratio and % open questions, pre and post, by condition | Table 8, Figure 5 |
| `behavioral_composites_by_group.csv` | Four technique composites (proportions), pre and post, by condition | Tables 5 and 7 |

`study1/` — Study 1 (expert validation) summaries, originally reported in Qiu et al. (2026):

| File | Contents | Manuscript |
|---|---|---|
| `authenticity_ratings.csv` | Mean (SD) authenticity ratings per configuration | Table 2 |
| `effectiveness_ratings.csv` | Mean (SD) instructional-effectiveness ratings per configuration | Table 3 |
| `figure3_discrimination_points.json` | Per-bar data points, means and SDs for the two discrimination tasks | Figure 3 |

Condition labels: `lecture_only` = classroom instruction only; `no_feedback` = AI practice without feedback; `feedback` = AI practice with the AI feedback module.

Participant-level data are not included (see the repository README).
